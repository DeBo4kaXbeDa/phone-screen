ЭКРАН ТЕЛЕФОНА — LINUX x86_64

Распакуйте архив и запустите ./PhoneScreen.
Python отдельно устанавливать не нужно. Папка _internal нужна для работы.
Требуется Linux с glibc 2.36+ (например, Debian 12 или Ubuntu 24.04).
Для ярлыка в меню приложений выполните ./install-shortcut.sh.

Телефон и ПК должны быть в одной локальной сети.
На Android 11+ включите «Для разработчиков → Беспроводная отладка».
В программе нажмите «Сопряжение по QR», на телефоне — «Сопряжение по QR-коду».
После сканирования программа найдёт адрес и попробует открыть экран со звуком.
Можно также ввести адрес и шестизначный код вручную.
Адрес подключения и адрес сопряжения используют разные порты.

При обрыве программа пытается восстановить связь в течение 45 секунд.
«Создать новый QR-код» обновляет код без перезапуска программы.
«Остановить» завершает трансляцию и отменяет повторные подключения.
Звук воспроизводится на ПК, управление телефоном отключено.

Журнал: ~/.local/state/phone-screen/connection.log
Лицензии сторонних компонентов находятся в папке licenses.
