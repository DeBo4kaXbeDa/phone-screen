# Экран телефона

Показывает экран Android со звуком на компьютере по локальной сети.
Поддерживает сопряжение по QR-коду и восстановление соединения после обрыва.
Управление телефоном отключено. Передача экрана работает через [scrcpy](https://github.com/Genymobile/scrcpy).

Нужен Android 11 или новее. Телефон и компьютер должны быть в одной сети.

## Windows

1. Скачайте `PhoneScreen-Windows-x64.zip` из [релизов](https://github.com/DeBo4kaXbeDa/phone-screen/releases/latest).
2. Полностью распакуйте архив и запустите `PhoneScreen.exe`.
3. Для ярлыка на рабочем столе запустите `Создать ярлык.vbs`.

Python устанавливать не нужно. Папка `_internal` должна оставаться рядом с exe.
Если Windows запросит доступ к сети, разрешите его для частной сети.
Сборка предназначена для Windows 10/11 x64; запуск проверен через Wine.

## Linux

1. Скачайте `PhoneScreen-Linux-x64.tar.gz` из [релизов](https://github.com/DeBo4kaXbeDa/phone-screen/releases/latest).
2. Распакуйте и запустите:

```sh
tar -xzf PhoneScreen-Linux-x64.tar.gz
cd PhoneScreen
./PhoneScreen
```

Python отдельно устанавливать не нужно. Сборка для Linux x86_64 с glibc 2.36+
(например, Debian 12, Ubuntu 24.04 и современные Arch/CachyOS).
Для ярлыка в меню приложений выполните `./install-shortcut.sh`.

## Подключение телефона

1. Включите на телефоне «Для разработчиков → Беспроводная отладка».
2. В программе нажмите «Сопряжение по QR».
3. На телефоне выберите «Сопряжение по QR-коду» и отсканируйте код.
4. После сопряжения программа попробует сама открыть экран и звук.

Также можно подключиться по шестизначному коду. Адрес из окна с кодом нужен
для сопряжения. Адрес с главного экрана беспроводной отладки нужен для
трансляции — порт у него другой.

После первого сопряжения обычно достаточно нажать «Показать экран».
При обрыве программа пытается восстановить связь в течение 45 секунд.
Если нужно повторить сопряжение, нажмите «Создать новый QR-код».
Кнопка «Остановить» завершает трансляцию и отменяет повторные подключения.

Звук воспроизводится на ПК; на телефоне на время трансляции он отключается.
Некоторые приложения запрещают захват защищённого содержимого.

## Запуск из исходников

Нужен Python 3.12 или новее.

```sh
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python3 prepare_vendor.py
python3 main.py
```

В Windows вместо активации выше используйте `.venv\Scripts\activate`.

## Сборка и проверки

- Linux: `python3 build_linux.py` — нужен Docker.
- Windows: `python3 build_windows.py` на Linux — нужны Wine и Pillow.
- Проверки на Linux: `python3 -m unittest -v` — для чтения тестового QR нужен `zbarimg`.

Архивы создаются в `dist/`. Сторонние компоненты скачиваются при подготовке
или сборке; бинарные файлы, журналы и ключи сопряжения в Git не хранятся.
