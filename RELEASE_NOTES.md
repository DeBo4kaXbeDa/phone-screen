Первый выпуск «Экран телефона».

- Экран Android со звуком по локальной сети.
- Сопряжение по QR-коду или шестизначному коду.
- Поиск адреса и восстановление связи после обрыва.

Windows: распакуйте `PhoneScreen-Windows-x64.zip` и запустите `PhoneScreen.exe`.
Linux: распакуйте `PhoneScreen-Linux-x64.tar.gz` и запустите `./PhoneScreen`.
Python входит в обе сборки. Linux требует glibc 2.36+; Windows — 10/11 x64.
Подключение и инструкции описаны в README.

Проверки: автоматические тесты и запуск Linux; запуск Windows через Wine.
