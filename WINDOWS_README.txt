ЭКРАН ТЕЛЕФОНА — WINDOWS 10/11 x64

1. Полностью распакуйте архив в обычную папку.
2. Запустите PhoneScreen.exe. Python устанавливать не нужно.
3. Для ярлыка на рабочем столе дважды нажмите «Создать ярлык.vbs».

ПОДКЛЮЧЕНИЕ
Телефон и ПК должны быть в одной локальной сети.
На Android 11+ включите «Для разработчиков → Беспроводная отладка».
В программе нажмите «Сопряжение по QR», на телефоне выберите
«Сопряжение по QR-коду» и сканируйте код с экрана компьютера.
После сопряжения программа найдёт адрес и попробует открыть экран со звуком.
Если Windows попросит разрешить доступ к сети, разрешите для частной сети.

Если поиск не сработал, можно ввести IP:порт с главного экрана
«Беспроводная отладка» и нажать «Показать экран».
Порт подключения отличается от порта, показанного вместе с цифровым кодом.
При повторных подключениях новое сопряжение обычно не требуется.

Экран и звук передаются на ПК; управление телефоном отключено.
Громкость настраивается обычным микшером Windows.
Закройте окно экрана или нажмите «Остановить», чтобы закончить трансляцию.
После обрыва программа до 45 секунд пытается восстановить соединение.
Кнопка «Создать новый QR-код» позволяет повторить сопряжение без перезапуска.

Файлы в папке _internal нужны для работы: не переносите отдельно только exe.
Программа не требует прав администратора и установки драйверов для Wi-Fi.
Журнал: %LOCALAPPDATA%\PhoneScreen\connection.log

КОМПОНЕНТЫ
Python, PySide6/Qt, scrcpy/ADB, qrcode и zeroconf входят в сборку.
Версии, источники и SHA-256 указаны в components.json; лицензии — в licenses
и в папке _internal\vendor\scrcpy-win64-v5.0.1.
Исходный проект scrcpy: https://github.com/Genymobile/scrcpy
